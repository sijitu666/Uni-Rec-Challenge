### 方案 3.2：手动配置 Hooks（轻量级）

**Step 1：创建通知脚本**

```bash
mkdir -p ~/.claude/hooks
```

创建 `~/.claude/hooks/feishu-notify.sh`：

```bash
#!/bin/bash

# 飞书 Webhook 地址
FEISHU_WEBHOOK="https://open.feishu.cn/open-apis/bot/v2/hook/YOUR_WEBHOOK_URL"

# 从 stdin 读取 Claude Code 传递的 JSON 数据
read -r input

# 提取关键信息
PROJECT_DIR=$(echo "$input" | jq -r '.workspace_roots[0] // "未知目录"')
EVENT_TYPE=$(echo "$input" | jq -r '.hook_event_name')
TIMESTAMP=$(date '+%Y-%m-%d %H:%M:%S')

# 根据事件类型设置消息内容
case "$EVENT_TYPE" in
  "Stop")
    TITLE="✅ Claude Code 任务完成"
    COLOR="green"
    MESSAGE="项目：$PROJECT_DIR\n时间：$TIMESTAMP\n状态：任务已结束"
    ;;
  "Notification")
    TITLE="⚠️ Claude Code 需要确认"
    COLOR="yellow"
    MESSAGE="项目：$PROJECT_DIR\n时间：$TIMESTAMP\n状态：等待用户操作"
    ;;
  "PostToolUseFailure")
    TITLE="❌ Claude Code 工具执行失败"
    COLOR="red"
    MESSAGE="项目：$PROJECT_DIR\n时间：$TIMESTAMP\n状态：执行出错"
    ;;
  *)
    TITLE="📢 Claude Code 通知"
    COLOR="blue"
    MESSAGE="项目：$PROJECT_DIR\n时间：$TIMESTAMP\n事件：$EVENT_TYPE"
    ;;
esac

# 发送飞书消息（使用富文本卡片）
curl -X POST -H 'Content-Type: application/json' \
  -d "{
    \"msg_type\": \"interactive\",
    \"card\": {
      \"config\": { \"wide_screen_mode\": true },
      \"header\": {
        \"title\": { \"tag\": \"plain_text\", \"content\": \"$TITLE\" },
        \"template\": \"$COLOR\"
      },
      \"elements\": [
        {
          \"tag\": \"div\",
          \"text\": { \"tag\": \"lark_md\", \"content\": \"$MESSAGE\" }
        }
      ]
    }
  }" \
  "$FEISHU_WEBHOOK"
```

设置可执行权限：
```bash
chmod +x ~/.claude/hooks/feishu-notify.sh
```

**Step 2：配置 Claude Code Hooks**

编辑 `~/.claude/settings.json`：

```json
{
  "hooks": {
    "Stop": [
      {
        "command": "bash ~/.claude/hooks/feishu-notify.sh",
        "async": true
      }
    ],
    "Notification": [
      {
        "command": "bash ~/.claude/hooks/feishu-notify.sh",
        "async": true
      }
    ],
    "PostToolUseFailure": [
      {
        "command": "bash ~/.claude/hooks/feishu-notify.sh",
        "async": true
      }
    ]
  }
}
```

**Step 3：测试**

```bash
claude
# 执行任意任务，完成后检查飞书是否收到通知
```

```bash

```

```bash
#!/bin/bash

FEISHU_WEBHOOK="https://open.feishu.cn/open-apis/bot/v2/hook/YOUR_WEBHOOK_URL"

# 读取输入
read -r input

    TEXT="即将执行 Shell 命令"
    ;;
  "afterFileEdit")
    EMOJI="📝"
    TEXT="文件已编辑"
    ;;
  *)
    EMOJI="📢"
    TEXT="Cursor 通知"
    ;;
esac

# 发送飞书消息
curl -X POST -H 'Content-Type: application/json' \
  -d "{
    \"msg_type\": \"text\",
    \"content\": {
      \"text\": \"$EMOJI $TEXT\\n📁 项目：$WORKSPACE\\n🕐 时间：$TIME\\n📌 事件：$EVENT\"
    }
  }" \
  "$FEISHU_WEBHOOK"
```

### 方案 5.2：手动配置 notify

**Step 1：创建通知脚本**

创建 `~/.codex/notify.py`：

```python
#!/usr/bin/env python3
import sys
import json
import urllib.request
import os

FEISHU_WEBHOOK = "https://open.feishu.cn/open-apis/bot/v2/hook/YOUR_WEBHOOK_URL"

def main():
    # 读取 Codex 传递的 JSON
    payload = json.load(sys.stdin)
    
    # 构建消息
    message = {
        "msg_type": "text",
        "content": {
            "text": f"✅ Codex 任务完成\n📁 目录：{os.getcwd()}\n📊 状态：{payload.get('status', '完成')}"
        }
    }
    
    # 发送飞书通知
    req = urllib.request.Request(
        FEISHU_WEBHOOK,
        data=json.dumps(message).encode('utf-8'),
        headers={'Content-Type': 'application/json'},
        method='POST'
    )
    
    with urllib.request.urlopen(req) as response:
        print(f"通知发送状态: {response.status}")

if __name__ == "__main__":
    main()
```

**Step 2：配置 Codex**

编辑 `~/.codex/config.toml`：

```toml
notify = ["python3", "~/.codex/notify.py"]
```

或使用命令行配置：
```bash
codex config set notify "python3 ~/.codex/notify.py"
```

## 九、常见问题

### Q1: Windows 系统支持吗？
- Claude Code / Cursor：✅ 支持（使用 WSL 或 Git Bash）
- Codex CLI：✅ 支持
- Trae：✅ 原生支持

### Q2: 可以发送到个人聊天而不是群聊吗？
需要创建**飞书自建应用**（非群机器人），使用 `im:message.p2p_msg` 权限。

### Q3: 如何自定义通知内容？
修改脚本中的 JSON payload，支持：
- `msg_type: text` - 纯文本
- `msg_type: interactive` - 富文本卡片
- `msg_type: markdown` - Markdown 格式

### Q4: 通知没收到怎么办？
1. 检查 Webhook URL 是否正确
2. 检查脚本是否有执行权限 (`chmod +x`)
3. 查看工具日志（Claude Code: `~/.claude/logs/`）
4. 手动运行脚本测试

## 十一、详细实战方案（结合博客经验）

### 11.1 Claude Code 详细方案

#### 方案 A：使用 claude-code-hooks-feishu（最推荐）

**实战案例来源**：
- [让飞书提醒你不要摸鱼过头 - Claude Code](https://edgesky.cn/article/nfd732l0/)
- [npm: claude-code-hooks-feishu](https://www.npmjs.com/package/claude-code-hooks-feishu)

**核心优势**：
| 功能 | 说明 |
|------|------|
| 任务完成通知 | Claude 完成响应时自动发送飞书消息 |
| 权限请求通知 | 需要用户确认时推送通知 |
| 工具失败通知 | 执行出错时及时提醒 |
| 危险命令拦截 | 自动拦截 `rm -rf` 等危险操作 |
| **双向交互** | 飞书上可直接回复继续对话/审批权限 |

**安装步骤**：
```bash
# 一键安装（交互式向导）
npx claude-code-hooks-feishu
```

安装过程中会提示：
1. 选择通知方式（群机器人 Webhook / 自建应用）
2. 输入飞书 Webhook URL 或 App ID/Secret
3. 选择是否启用双向交互

**启动双向交互守护进程**：
```bash
# 启动守护进程（必须，否则无法接收飞书回复）
npx claude-code-hooks-feishu --daemon start

# 查看状态
npx claude-code-hooks-feishu --daemon status

# 停止
npx claude-code-hooks-feishu --daemon stop
```

**工作原理**（来自博客实战经验）：
```
Claude Code Hook → 发送交互卡片到飞书 → 等待用户操作
                                          ↓
飞书用户操作 → WebSocket 守护进程接收 → 写入响应文件
                                          ↓
Hook 读取响应 → 输出决策给 Claude Code ← 继续/停止
```

**通知卡片示例**：

| 事件 | 卡片标题 | 颜色 | 操作 |
|------|---------|------|------|
| 任务完成 | ✅ Claude Code 任务完成 | 🟢 绿色 | 输入框继续对话 |
| 权限请求 | ⚠️ Claude Code 需要确认 | 🟡 黄色 | 允许/拒绝按钮 |
| 工具失败 | ❌ Claude Code 工具执行失败 | 🟠 橙色 | 查看详情 |
| 危险拦截 | 🚨 危险命令已拦截 | 🔴 红色 | 查看命令 |

**实战技巧**（来自博客）：
> "守护进程未运行时，自动回退到普通通知模式" - 所以务必启动 daemon

> "实测因为脚本中的转义字符与 cmd 或 powershell 中的转义字符问题，Windows 上通过 hooks 发起请求始终无法成功，建议 Linux/Mac 使用"

   - 开通权限：`im:message`、`im:message.p2p_msg`、`im:message.group_at_msg`

3. **使用 Rules 强制触发通知**
   - 创建 `.trae/rules/notification.md`
   - 强制要求每次对话结束发送通知

**实战技巧**：
> "这种方式同样适用于其他 AI IDE 或者支持 MCP 协议的应用"

> "飞书云文档 MCP 需要使用所选身份的权限执行操作" - 注意权限配置

---

#### 方案 B：使用 Rules + 手动触发（保底方案）

如果 MCP 配置复杂，可以用纯 Rules，用户需要显式触发：
```
任务完成了，发送飞书通知
```
